# Formula references

QuantStats (https://github.com/ranaroussi/quantstats), Apache License 2.0, version 0.0.77, is a formula reference and cowork-only numerical test oracle for the daily marked-equity metrics. The TypeScript implementation is independently authored; no upstream source, UI, assets or documentation text is copied. Generated input/expected-value fixtures and explicit convention differences are described in docs/RESULTS.md. QuantStats is not a runtime dependency.

Probabilistic Sharpe Ratio: David H. Bailey and Marcos López de Prado, The Sharpe Ratio Efficient Frontier (2012). Independently implemented formula, with population-moment/daily-SR conventions and assumptions recorded in docs/RESULTS.md.

Freqtrade/FreqUI, LEAN and OctoBot informed workflow/report/comparison ideas only. No code or assets from those repositories are included in this release. Existing project licence remains AGPL-3.0-only.
