# Staking sources

For 0.5.0 source links, permission checks, verified response examples and limitations, read [DATA-SOURCES.md](DATA-SOURCES.md).

All feeds are now user-enabled and off by default. The 0.4.0 source-limited Lido screenshots are historical renders, not the current connector settings. No provider data is bundled as runtime seed data. Test-only recorded responses and official examples are labelled and copied only into the build/test stage.

Rates are neutral observations, not recommendations. APR is distinct from APY; ranges, unverified annualization bases, tiered/multi-coin rewards and unavailable fields stay unknown rather than becoming comparable rates. No inflation-adjusted yield is invented. A successful fetch does not establish EU/France availability or data-reuse permission.
